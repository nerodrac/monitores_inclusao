# monitores_inclusao
Banco de dados e implementação de um Sistema de Monitoramento de Monitores de Inclusão.
Este repositório disponibiliza o modelo conceitual, lógico e a implementação inicial de um software em python destinado a apoiar equipe de Monitores de Inclusão no IFRJ Campus Niterói.

1. A modelagem conceitual foi construída considerando a ferramenta brModelo e define as quatro entidades centrais do sistema, seus atributos e suas chaves primárias.

2. A modelagem lógica separa as entidades e a entidde-relacionamento em formato de tabela, sinalizando as chaves primárias e chave estrangeiras (quando houver).
